# 构造函数
- 被 new 调用的函数
- 用于批量创建对象实例

1. JS官方提供了 Object、Array等构造函数，用于创建对象实例

## prototype 原型 （显式原型）
- prototype 是每一个函数天生就拥有的属性，且它是一个对象

## __proto__ 对象原型 （隐式原型）
- __proto__是对象天生拥有的属性，且它是一个对象

### 实例对象的隐式原型一定等于构造函数的显式原型
- V8 引擎在访问对象中的属性时，会先查找对象本身显示拥有的属性，如果找不到，就会去查找对象的隐式原型

# 包装类
- 原始类型不能添加属性和方法
 1. 当用户创建一个字面量时，V8 会默认执行 new Xxx() ,得到一个对象实例
 2. 因为原始类型不能增加属性和方法，所以V8 在new 出这个实例对象后，会立即做一个拆箱操作
 3. 所以给原始类型添加属性和方法，最后访问得到的其实是实例对象上不存在的属性和方法，也就是undefined
