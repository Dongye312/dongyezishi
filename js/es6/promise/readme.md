# 代码的执行耗时吗？
- 持续中存在一些耗时的任务，比如：网络请求、定时器等，这些任务我们称作异步任务。

# 异步
- JS 默认是单线程执行的：意味着同一时间只能执行一个任务。

- 耗时任务会阻塞后续代码的执行，这样会降低程序的执行效率。所以JS 设计了一个 事件循环机制，来处理异步任务。

# 处理异步任务
- JS 会将同步任务先执行完毕后，再执行异步任务。而在某种场景下，我们是希望非得等某个异步任务执行完毕，才能执行后续代码。

1. 回调函数
   将后面要执行的函数作为参数传给前面的异步函数，这就会导致前面的异步函数执行完毕后，才会调用后面要执行的函数。
   缺点：当异步函数嵌套过多时，会导致回调地狱问题（排查问题困难，代码可读性低，代码维护困难）。

   # Promise 工作原理
   你交给Promise一个异步任务，Promise一开始标记状态为等待，同时把你在then、catch里写好的成功、失败回调先收起来存好，不会立刻执行；等异步任务跑完，调用resolve就把状态改成成功、取出成功回调运行，调用reject就改成失败、取出失败回调运行
